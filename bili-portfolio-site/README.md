# Bili Yuniarto Portfolio Website

A responsive static portfolio for GitHub Pages.

## Upload to GitHub Pages

1. Open the `biliyuniarto.github.io` repository.
2. Click **Add file → Upload files**.
3. Extract the ZIP first, then upload **all files and folders inside this package**. Do not upload the ZIP itself.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
7. Click **Save** and wait several minutes.
8. Open `https://biliyuniarto.github.io/` and refresh with `Ctrl + Shift + R`.

## Important before publishing

- The website uses public-safe summaries and does not include private dashboard screenshots or customer data.
- The downloadable CV currently contains specific internal performance metrics. Confirm that those numbers are safe to publish publicly. If not, replace `assets/Bili-Yuniarto-CV.pdf` with a public-safe CV using the exact same file name.
- Replace or update project copy as more public portfolio evidence becomes available.

## Main files

- `index.html` — page content and SEO metadata
- `style.css` — responsive visual design
- `script.js` — mobile menu, reveal effects, and copy-email interaction
- `assets/Bili-Yuniarto-CV.pdf` — downloadable CV
- `assets/favicon.svg` — site icon
- `assets/og-image.png` — social sharing image
